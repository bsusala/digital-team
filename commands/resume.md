# Resume From Handover

Load the session handover document and get up to speed immediately.

## Instructions

1. **Detect project type** and read the version source:
   - Rust: `Cargo.toml`
   - Node: `package.json`
   - Python: `pyproject.toml` or `setup.py`
   - PHP: `composer.json`
   - Other: check for any common manifest file

2. **Load context** by reading (skip any that don't exist):
   - `docs/CONTINUATION.md` (full session context — the primary handover document)
   - `docs/ROADMAP.md` (strategic direction, if it exists)
   - `CHANGELOG.md` (top section only — latest version entry)
   - The auto-memory file at the path shown in your system prompt

3. **Check current state** by running:
   - `git log --oneline -5` (what happened most recently)
   - `git status` (any uncommitted work in progress)
   - `gh issue list` (current open issues — skip if no remote or gh unavailable)

4. **Present a brief status report** to the user:
   - Project name and current version
   - What was completed last session
   - What's next on the roadmap
   - Any uncommitted changes or work in progress
   - Open issue count (if available)

5. **End with**: "Ready to continue. What would you like to work on?"

Keep the status report concise — no more than 15-20 lines. This is a quick orientation, not a document dump.
